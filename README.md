# 魔兽争霸 III 崩溃分析工具 (War3CrashAnalyzer) - 开发文档

本工具是一个专为魔兽争霸 III (War3) 地图开发者设计的集成分析环境，旨在通过静态审计、实时监控和泄露定位&修复技术，定位并解决地图崩溃、内存泄露及同步失效 (Desync) 问题。

## 🏗 项目架构

项目采用模块化设计，将界面 (GUI)、业务逻辑 (Core) 与底层引擎 (Engine) 彻底解耦，方便后续功能扩展与 AI Agent 维护。

### 目录结构说明

```text
war3crashanalyzer/
├── main.py                 # 项目启动入口
├── analyzer_config.json    # 用户配置文件 (自动生成)
├── core/                   # 核心业务逻辑模块
│   ├── auditor.py          # 静态审计、资源提取与崩溃日志分析
│   ├── fixer.py            # JASS 脚本泄露定位&修复引擎
│   ├── reporter.py         # 云端数据上报与后台定期任务
│   ├── knowledge.py        # 崩溃偏移量知识库 (包含各版本 Game.dll 地址)
│   └── constants.py        # JASS 语法常量与正则表达式定义
├── engine/                 # 底层交互模块
│   └── memory.py           # Windows API 封装、JASS VM 监控、句柄追踪
├── gui/                    # 界面组件模块
│   ├── app.py              # GUI 调度中心，负责组装各功能标签页
│   └── tabs/               # 功能标签页独立实现
│       ├── base.py         # 标签页基类 (定义了统一的日志与状态接口)
│       ├── static_tab.py   # 静态审计界面
│       ├── local_tab.py    # 本地调试/实时监控界面
│       ├── leak_fix_tab.py # 泄露定位&修复界面
│       └── adv_tab.py      # 高级工具与系统设置界面
└── assets/                 # 图标、图片等静态资源
```

## 🛠 核心组件功能

### 1. 静态审计 (Core.Auditor)
*   **强力提取**：利用常用字典从 MPQ/W3X 中提取核心脚本与配置文件。
*   **资源审计**：扫描模型路径、贴图有效性及单位数据引用。
*   **崩溃日志分析**：读取 `Errors/*.txt` 日志，匹配 `knowledge.py` 中的偏移量地址，输出中文诊断结论。

### 2. 内存监控 (Engine.Memory)
*   **JassVMMonitor**：通过读取 `Game.dll` 内存，追踪 JASS 虚拟机的活跃线程、调用栈偏移量。
*   **AgentMonitor**：实时监控引擎对象（单位、点、组、计时器等）的句柄计数与内存占用。
*   **句柄快照**：对比不同时间点的句柄状态，精准定位内存泄露源。

### 3. 泄露定位&修复 (Core.Fixer)
*   基于插桩技术，自动扫描 `war3map.j` 并在局部变量作用域结束前插入销毁函数（如 `RemoveLocation`, `DestroyGroup`）。

## 🚀 开发者指南 (AI Agent 更新须知)

如果您需要为本项目添加新功能，请遵循以下约定：

1.  **添加新功能标签页**：
    *   在 `gui/tabs/` 目录下新建一个类，继承自 `BaseTab`。
    *   在 `gui/app.py` 的 `setup_ui` 方法中实例化并添加到 `notebook`。
2.  **更新崩溃知识库**：
    *   直接修改 `core/knowledge.py` 中的 `CRASH_KNOWLEDGE` 字典，无需改动逻辑代码。
3.  **底层 API 扩展**：
    *   如果需要新的 Windows API 或内存读取逻辑，请在 `engine/memory.py` 中封装，不要直接写在 GUI 类里。
4.  **日志输出**：
    *   在 UI 类中调用 `self.log("消息")`，该消息会同步显示在界面的诊断日志区域。

## 📦 依赖项

项目依赖以下第三方库，启动时会自动检查并安装：
*   `psutil`: 进程与内存监控
*   `mpyq`: MPQ 地图包解析
*   `pillow`: 图像处理 (用于 UI 图标与系统托盘)
*   `pystray`: 系统托盘图标支持

## 💡 交互说明

*   **关闭窗口**：点击关闭按钮时，程序会弹出对话框询问：
    *   **是**：最小化到系统托盘，后台持续运行自动上报功能。
    *   **否**：彻底退出程序，停止所有后台任务。
*   **系统托盘**：右键点击托盘图标可选择“显示主界面”或“退出程序”。

## ⚠️ 安全警告

本工具涉及进程注入与内存读取，**严禁在任何联网对战平台（如 KK、网易、官方战网）运行**。仅建议在单机测试环境下进行地图压力测试与调试，否则有封号风险。
